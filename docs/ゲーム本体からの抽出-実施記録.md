### 生成物

プロジェクトのパーサー(`src/parsers/localization.ts`)をそのまま使って生成した。
自前実装だとハッシュ関数や取り込みグループがずれるため。

- `data/localization.japanese.json` — 既存の `localization.english.json` と同じスキーマ。10,550トークン
- `data/i18n/ja.json` — 対訳辞書。トークンID → `ja` + `hash`

```json
{ "schemaVersion": 1,
  "counts": { "total": 10616, "translated": 10550, "needsTranslation": 66 },
  "tokens": {
    "upgrade_clip_size": { "ja": "基礎拡張マガジン",
                           "group": "citadel_gc_mod_names",
                           "hash": "b0e7e0a4c4f1" } } }
```

`hash` は `localization.english.json` の同トークンの `hash` をそのまま持つ(sha1 先頭12桁)。
パッチで英語が変われば差分で「要再翻訳」を検出できる。
公式訳が無いトークンは `needsTranslation: true` と `en`(英語原文)を持つ。

## 手順2 — 抽出

Source2Viewer CLI 20.0（ValveResourceFormat 公式リリースの `cli-windows-x64.zip`）を使用。
GUIのクリック操作ではなく、コマンドを書いたバッチファイルで実行した。パッチのたびに再実行できる。

```
Source2Viewer-CLI.exe -i "<citadel>\pak01_dir.vpk" -o <out> --vpk_filepath "panorama/images/items" --vpk_decompile
```

対象フォルダ: `panorama/images/` 配下の `items` `upgrades` `hud/abilities` `hud/icons` `heroes` `npcs`。
合計 1,041 PNG + 108 SVG を書き出し、その中から manifest の393件を選別した。

> **手順書の漏れ**: `panorama/images/npcs/` が対象フォルダ一覧に無く、
> `vanguard_aoe_buff` の1件だけ取れなかった。追加実行で解決済み。

## 手順3 — 照合と配置

`image-manifest.json` の `vpkPath` → `outPath` を機械的に突き合わせた。推測での紐付けはしていない。

- `.vtex_c` → `.png`、`.vsvg_c` → `.svg`（`icon_speed` の1件のみSVG）
- ファイル名から `_psd` を除去
- 393件すべてPillowで開けることを確認（SVGの1件を除く）

配置後、プロジェクト自身の照合機能で再検証した。

```
node --experimental-strip-types src/parsers/image-manifest.ts .
  必要な画像 393 件 (vtex_c 392 / vsvg_c 1)
  public/ に存在 393 件 / 未取得 0 件
```

> `items.json` には `items/brawl/` を参照するアイテムが23件あるが、
> すべて `inShop: false`(Brawl専用でショップ非掲載)のため manifest が意図的に除外している。
> 不足ではない。
